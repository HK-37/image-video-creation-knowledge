# image-video-creation-knowledge — 影像创作专业知识库

> 面向 AI 生图、生视频的影像创作知识底座。按创作决策与视听统筹、视听创作与素材生产、AI 技术控制与后期交付三层组织，共 74 条正式知识条目。

**版本：1.0.0（私有知识库基线）**  
**可见性：私有；不开源，不附带 MIT 或其他开放许可证。**

## 内容边界

本仓库只收录正式创作知识及必要的组织、复核与证据资料：

- `kb/MOC-index.md`：总导航与使用顺序。
- `kb/20-影视知识/`：74 条正式知识。
- `kb/00-规范/`：知识库规范与独立复核记录。
- 根目录 5 份框架与证据文件：仅保留正式文件直接引用的必要材料。

不包含工作日志、任务交接、早期生成试验、接口状态、论文 PDF、原始图片/视频、个人记忆或访问凭据。制片管理与法规合规属于另一资料体系，不在本仓库。

## 使用

从 `kb/MOC-index.md` 开始，按任务选择相关条目。每条区分：

1. **来源命题**：公开资料实际支持的内容。
2. **项目转译**：如何用于本项目创作与检查。
3. **可观察验收**：通过、失败、无法判定的依据。
4. **不适用条件**：不能外推的范围与证据限制。

所有正式条目的 `status` 仍为 `未验证`：这里指尚未完成本项目的真实生成验证，不是知识条目尚未建立。1.0.0 表示知识库的结构、内容和证据边界达到可用基线，不表示影像知识已穷尽或提示词效果已验证。

## 与提示词优化 Skill 的关系

知识库是独立数据资产，不随开源 Skill 自动克隆。Skill 的宿主在有访问权限时按索引读取相关条目；无知识库时降级为 Skill 的公开规则。

本仓库不是公开子模块，不给外部用户预设访问权限。授权通过 GitHub 协作者、受控部署钥匙或内部接口单独处理。

## 证据与权利

条目保留公开 URL 供回查，采用提炼、重新组织与项目转译，不复制整段论文、教材或课程材料。第三方来源不随本仓库被重新授权；使用与分发时应分别遵守其权利与许可。

## 版本与维护
