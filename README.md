# image-video-creation-knowledge — 影像创作专业知识库

> 面向 AI 生图、生视频的影像创作知识底座。按创作决策与视听统筹、视听创作与素材生产、AI 技术控制与后期交付三层组织，共 74 条正式知识条目。

## 内容边界

本仓库只收录正式创作知识及必要的组织、复核与证据资料：

- `kb/MOC-index.md`：总导航与使用顺序。
- `kb/20-影视知识/`：74 条正式知识。
- `kb/00-规范/`：知识库规范与独立复核记录。
- 根目录 5 份框架与证据文件：仅保留正式文件直接引用的必要材料。

不包含工作日志、任务交接、早期生成试验、接口状态、论文 PDF、原始图片/视频、个人记忆或访问凭据。制片管理与法规合规属于另一资料体系，不在本仓库。

## 使用

从 `kb/MOC-index.md` 开始，按任务选择相关条目。每条区分：

1. **来源命题**：公开资料实际支持的内容。
2. **项目转译**：如何用于本项目创作与检查。
3. **可观察验收**：通过、失败、无法判定的依据。
4. **不适用条件**：不能外推的范围与证据限制。

所有正式条目的 `status` 仍为 `未验证`：这里指尚未完成本项目的真实生成验证，不是知识条目尚未建立。1.1.0 表示知识库的结构、内容和证据边界达到可用基线，并明确开放许可，不表示影像知识已穷尽或提示词效果已验证。

## 与提示词优化 Skill 的关系

知识库是独立数据资产，与开源 Skill 分仓库维护。使用者可以单独克隆本库，或在宿主项目中将其作为数据依赖，由 Agent 按索引读取相关条目；仅克隆 Skill 不等于已经配置本知识库。

建议将本库放在项目约定的 `knowledge/image-video-creation/` 目录，固定使用 `v1.1.0` 或后续明确版本。具体接入步骤见 Skill 仓库的 `docs/knowledge-source.md`。
