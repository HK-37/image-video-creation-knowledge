# 影像创作知识库索引

## 框架与使用边界

本库按 `框架V1.1` 组织 AI 生图、生视频创作所需的专业知识：A 层负责创作决策与视听统筹，B 层负责视听创作与素材生产，C 层负责 AI 技术控制、后期与交付。本库只收影像创作专业知识；制片管理（资源、成本、版本留痕）与法规合规（版权授权、肖像声音、生成内容标识与发布）不属于创作知识，另存于项目根目录 `制片与法规资料/`，创作判断不得以其代替，反之亦然。

这是项目应用架构，不是行业标准部门表，也不意味着所有内容调研已完成。专业事实、项目转译、模型能力与单案例经验分开记录；条目进入本库不等于已成为 Skill 的默认规则。

## A1 创作定位与任务简报

| 条目 | 核心对象 | 使用边界 |
|---|---|---|
| [[CON-A1-01-受众用途与观看情境]] | 用途、受众、观看目标、交付载体与可访问性 | 受众意图不等于统一反应；观看目标不等于传播转化 |
| [[CON-A1-02-主体核心信息与变化边界]] | 主体、核心信息、不可变项、允许变化项与未决项 | 项目授权边界不是永恒清单；参考风格不是事实依据 |
| [[CON-A1-03-创作简报的输入资源协同与验收]] | 输入依据、资源、协作、决策权限与版本化验收 | 简报不代替剧本/分镜/技术方案；中间方案通过不等于成品验收 |
| [[CON-A1-04-非叙事静态图短视频与效果边界]] | 非叙事、静态图、短视频的最小必要方案与效果证据 | 不强套三幕/人物弧光；内容理解、情绪、点击与转化分别取证 |

**A1 使用顺序**：先明确用途、受众与交付情境，再确定主体/核心信息和变化边界，随后把输入、资源、决策及验收组织为版本化创作简报；按静态图、非叙事或视频任务选择必要步骤，不把观看目标直接写成已实现的传播效果。

1. 先按任务选定创作定位、核心目标与不可妥协项；叙事任务依次检查行动目标、阻力因果、场景变化与信息安排，非叙事任务明确不适用的剧作维度。
2. 有外观参考时，先登记身份与允许改变项，再区分表面修饰和几何改变。
3. 表演任务写行动、可见身体行为和表情时间过程；有交互时补接触方向与遮挡。
4. 从剧本/创意按需选择标记剧本、镜头清单、俯视图或故事板，保持剧本、视觉计划、调度和最终剪辑的区别。
5. 生成后逐项记录通过、失败或无法判定，核心失败不以其他局部改善抵消。
