# 调色编码与交付

## 来源命题

ITU-R BT.709-6 是 ITU 针对 HDTV 制作与国际节目交换的参数标准，规定图像格式、帧率、扫描、色度学、信号格式等制作/交换参数。它不是「套一个 Rec.709 LUT」的等价物，也不是互联网播放通用规范。

- ITU-R BT.709-6：https://www.itu.int/rec/R-REC-BT.709-6-201506-I/en

ITU-R BT.1886-0 是 HDTV 演播室参考显示设备的 EOTF（电光转换函数）标准，规定参考监视器在 BT.709 信号下的亮度响应。它管的是「参考显示端如何响应信号」，不规定内容调色或互联网播放端。

- ITU-R BT.1886-0：https://www.itu.int/rec/R-REC-BT.1886-0-201103-I/en

EBU R103 是 EBU 关于数字电视信号容差（preferred signal levels）的建议，规定视频信号电平、RGB 范围等容差区间。它是信号技术合规建议，不是内容审美验收标准。

- EBU R103：https://tech.ebu.ch/docs/r/r103.pdf

综合：BT.709 / BT.1886 / EBU R103 各自规范制作参数、参考显示响应、信号容差的不同侧面，均不替代创作调色判断，也不是「加标签 = 达标」的开关。标准版本需逐项目确认，不能假定最新版即适用。

## 项目转译

按以下链条逐环节留痕，任何环节未完成即视为该环节未通过：

素材验收（C1-04）→ 合成（C1-05）→ 明确色彩管理链下调色 → 母版输出 → 按交付规格编码 → 实机 QC。

- **色彩管理链**：显式记录输入源色彩空间、工作空间、显示变换、目标输出色彩空间；调色过程使用的 LUT/CDL/曲线、版本与创建人须记录；不允许「套 Rec.709 LUT」作为唯一色彩管理动作。
- **母版**：母版文件的色彩空间、EOTF、位深、色度抽样、动态范围标签须与色彩管理链一致；母版作为后续编码的唯一源。
- **按交付规格编码**：明确目标平台的容器、编码器、码率、分辨率、帧率、色彩标签（primaries / transfer / matrix / range）；不同平台（电视/网络/移动端）分别记录。
- **实机 QC**：在目标设备/播放器上实际播放验证；不能只在软件时间线上确认。

三个独立验收栏：
- **元数据**：色彩 primaries、transfer function、matrix、range、HDR 静态/动态元数据是否齐全且与内容一致。
- **解码播放**：实际设备/播放器能否正确解码；解码后颜色/亮度/对比度是否在 BT.1886 参考显示条件下符合预期。
- **输出规格**：容器、编码、码率、分辨率、帧率、声画同步是否符合交付方规格；EBU R103 信号容差（如适用）是否满足。

标准版本逐项目确认：BT.709-6、BT.1886-0、EBU R103 各自版本与修订需在项目启动时登记，不能默认采用最新版。

## 可观察验收

- **通过**：色彩管理链、母版、编码、实机 QC 各环节留痕完整；元数据、解码播放、输出规格三栏均独立给出结论；标准版本已逐项目登记；实机 QC 在目标设备/播放器上实际验证。
- **失败**：把「套 Rec.709 LUT」当作完整色彩管理；缺少母版或色彩管理链记录；只在软件时间线上确认而不做实机 QC；三栏中任一栏缺失；把 BT.709/BT.1886/EBU R103 当审美验收标准。
- **无法判定**：缺少标准版本记录；缺少目标设备/播放器；缺少母版文件；色彩管理链未显式记录。

## 不适用条件

- **不能推出**：符合 BT.709/BT.1886/EBU R103 即代表创作调色正确或审美通过；「Rec.709 LUT」等同于完整色彩管理链；BT.1886 适用于互联网播放端或移动端显示；标准最新版自动适用于所有项目；元数据齐全即代表解码播放正确。
- **结论边界**：本条只规范「调色→编码→交付」链条的环节留痕与三栏验收，不规定具体色彩管理工具或 LUT、不替代 B3 颜色管理与创作调色分账、不预设具体交付平台规格。所有结论以本项目实际文件、目标设备与交付方规格为准。
