# 场景人物与摄影协同

## 来源命题

NFTS 的「Take One Painting」跨专业练习要求设计学生研究画作的历史背景、透视、显见光源、时代家具和建筑细节，完成比例平面/剖面、施工细节、搭建、涂装与陈设；摄影学生负责布光与拍摄，VFX 部门完成由设计学生绘制方案的 set extension。该教学分工直接支持区分美术的空间与物件、摄影的布光与拍摄、VFX 的延展及其接口，不能从单张成片把全部视觉结果归给其中一方。

- NFTS 官方课程大纲：https://nfts.co.uk/sites/default/files/Production_Design_MFA_Course_Outline_2026.pdf

AFI 的 DES 655 以 blocking 和 framing 为设计基础，DES 690 要求以剧本视觉分析、色彩流程、分镜、关键帧、平面图、模型、渲染、搭建及完成场景照片记录设计发展。它支持把空间设计、人物/摄影机组织与完成画面进行连续核对，不把概念图当作成片证据。

- AFI 课程说明：https://conservatory.afi.com/production-design-curriculum/

SDSA《GOTHAM》案例中，陈设师 **Andrew Baseman** 说明灯具造型需与 production designer 协商，gaffer 提出灯泡类型，陈设师与 DP 的对话从技术勘景开始；不同空间采用不同灯具，同时通过抛光地面、湿街与玻璃台面等配合反射。灯具是陈设物件，实际摄影照明是跨部门共同实现，不能把陈设师直接当布光师。

- SDSA《GOTHAM》，Andrew Baseman：https://www.setdecorators.org/?SHOW=SetDecor_features_Gotham&art=television_decor_features

SDSA《DICKINSON》的另一案例中，陈设师 **Marina Parker** 说明 Death 车厢被有意设计为 Emily 红裙的背景，使服装与两人的亲密关系成为焦点。这是《DICKINSON》的场景—服装协同案例，不与《GOTHAM》的 Andrew Baseman 混写。

- SDSA《DICKINSON》，Marina Parker：https://www.setdecorators.org/?SHOW=SetDecor_features_DICKINSON&art=television_decor&name=DICKINSON

## 项目转译

评审必须包含人物进入场景后的测试帧或完整片段，不能只看空景概念图、服装静物或 LUT 截图。将问题分为：美术可控项（空间、表面、环境物件）、人物造型协作项（服装、妆发、随身道具）、摄影可控项（机位、镜头、布光、曝光）与共同项（色材、实景光源、反射、人物图底、VFX 接口）。岗位名称及职责随项目而变，但返工对象须可定位。

预先核对场景尺度、开口、动线与候选机位；人物入场后检查轮廓、明度/色度与质感是分离、呼应还是有意融合；实景灯具同时检查美术造型、光源位置与技术可实施性；实体与数字延展检查透视、材质和光向的接续。以下为项目核验方案，尚未实测。

## 可观察验收

- **通过**：场景尺度、开口和动线支持必要表演与机位；人物与背景的图底关系符合意图；实景光源造型、位置和光线结果相容；反射面产生预期层次；实体场景与数字延展在透视、材质和光向上连续；问题能归入明确责任项。
- **失败**：空景漂亮但人物无法行动或拍摄；服装与背景无意粘连；以调色替代美术或修补空间/服装冲突；把陈设灯具选择等同全部布光；实体与延展部分各有一套透视、材质或光向逻辑。
- **无法判定**：只有空景、服装单图、后期剧照或单张最佳帧，缺少人物入镜测试、候选机位、完整运动或制作条件；不能从单张成片反推某效果仅由美术或仅由摄影造成。

## 不适用条件

- **不能推出**：人物和场景颜色不同就必然协同；所有影片必须采用同一色材对比；美术或摄影任一方能独立保证最终画面统一；教学分工可直接变成所有地区、团队的岗位边界。
- **结论边界**：本条用于项目协同与验收，不规定 production designer、art director、DP、服装或 VFX 的全球统一层级。非写实、拼贴或全数字场景仍需说明其内部接口规则；模型是否能在多镜保持场景与人物关系须逐项目验证，当前未实测。
