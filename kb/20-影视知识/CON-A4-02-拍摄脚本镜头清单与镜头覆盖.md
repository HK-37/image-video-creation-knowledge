# 拍摄脚本、镜头清单与镜头覆盖

## 来源命题

Proferes《Film Directing Fundamentals》把 shooting script 用作在剧本文本上标记 camera setups 和 coverage 的工作本，以核对各段可取得哪些影像，并供导演、摄影、助理导演、制片及剪辑协作。它不是 storyboard 的同义词。

- Routledge《Marking Shooting Script with Camera Setups》：https://www.taylorfrancis.com/chapters/mono/10.4324/9781315167480-11/marking-shooting-script-camera-setups-nicholas-proferes-laura-medina

Anderson 将 shot list 定义为需取得的精确镜头清单，通常按预期拍摄顺序而非剪辑顺序组织；storyboard 中的对话近景可以反复出现，但可能来自同一次拍摄。因此，画格数不能直接换算为机位数或素材条数。

- Routledge《The shot list》：https://www.taylorfrancis.com/chapters/mono/10.4324/9780240814940-6/shot-list

《Shooting the Scene》把 coverage 与剧本、场景、演员调度、构图、镜头清单、storyboard、屏幕方向及剪辑协作共同讨论，支持「覆盖是场景所需镜头的方案与集合」，而非单张分镜或 master shot 的别名。

- Routledge 官方书目：https://www.routledge.com/Shooting-the-Scene-The-Art-and-Craft-of-Coverage-for-Directors-and-Filmmakers/Rosman/p/book/9781003158691

术语存在语境差异：WGA《Screen Credits Manual》使用 final shooting script 认定最终剧作文本及编剧署名，并不因此证明它必然包含逐镜机位。该手册的证据范围是编剧署名规则，不是所有剧组文档格式的总定义。

- WGA 官方手册：https://wga.org/contracts/credits/manuals/screen-credits-manual

## 项目转译

在项目内分别登记：

1. **剧本文本版本**：故事、行动和对白的共同参考；如使用「拍摄脚本」名称，注明是否另含机位/覆盖标记。
2. **shot list**：镜头 ID、对应场景/节拍、镜头功能、主体与景别、必要机位/运动、取得方式及优先级。
3. **coverage**：为保留叙事和剪辑选择而需取得的镜头/素材集合，包括任务实际需要的整体关系、关键细节、视线或反应，不以数量多为目标。
4. **两种顺序**：拍摄/生成顺序与预期剪辑顺序分列；同一 setup 可对应多个预期剪辑使用位置，storyboard 画格与实际素材分别编号。

AI 生成可把「取得镜头」理解为生成候选素材，但清单中的计划不得直接标记为已实现。

## 可观察验收

- **通过**：每个必需镜头可追溯到场景/节拍功能，并能与 storyboard、setup 和实际素材 ID 对照；拍摄/生成顺序与剪辑顺序未混写；关键动作、物件、空间关系及必要反应均有对应素材或明确的替代方案。
- **失败**：把画格数当机位数；把 coverage 简化成 master shot 或机械堆镜；只有说话者而漏掉任务所需的关键反应/细节；清单虽长但无法覆盖关键情节；计划中的镜头被当作已生成、已拍得的合格素材。
- **无法判定**：素材尚未取得、编号关系缺失，或无法确认同一 setup 的不同剪辑用途；不能据空白清单推断覆盖已经充分。

## 不适用条件

- **不能推出**：shooting script 在所有地区、团队都具有同一格式；coverage 必须采用「全景—过肩—特写」固定公式；镜头越多越容易剪辑；已有覆盖计划即可保证成片连贯。
- **结论边界**：WGA 条目只用于提示术语边界，不裁决具体剧组文档。是否需要完整 shooting script、shot list 和覆盖集合依任务而定；本条的项目字段尚未实测。
