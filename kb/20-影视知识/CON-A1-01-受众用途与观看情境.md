# 受众、用途、观看目标与交付情境

## 来源命题

《Context and Narrative in Photography》（Short、Leet、Kalpaxi 编，Routledge，2019）将摄影功能、photographic brief、subject、audience/intention、statement of intent、audience response 以及 intention/interpretation/context 分列为独立章节，并区分单幅与系列照片。出版社介绍其目标是规划、发展和呈现有意义的、可交流的图像。该来源支持把受众、意图、语境与作品形式作为彼此不同的分析维度；目录本身不证明特定受众反应。

- 《Context and Narrative in Photography》，出版社页 Description 与 Table of Contents 第 1–4 章：https://www.routledge.com/9781000213195

W3C WCAG 2.2 SC 1.2.2 的适用对象是同步媒体中的预录音频，要求字幕（有明确例外）；其说明指出字幕使聋人或听障者能够观看同步媒体，并补充环境中无法听声音者等使用情境。它证明交付情境会影响信息是否可被接收，不是所有视频的普遍审美要求。

- W3C《Understanding SC 1.2.2: Captions (Prerecorded)》，Success Criterion / Intent / Benefits：https://www.w3.org/WAI/WCAG22/Understanding/captions-prerecorded.html

W3C WCAG 2.2 SC 1.2.5 处理预录同步媒体的音频描述，意图是让盲人或视力受损者获得视觉信息。它支持在明确适用标准时检查视觉信息替代通道，不支持用音频描述替代原作的画面创作。

- W3C《Understanding SC 1.2.5: Audio Description (Prerecorded)》，Success Criterion / Intent：https://www.w3.org/WAI/WCAG22/Understanding/audio-description-prerecorded.html

**来源核对限制**：本条依据出版社目录/介绍与 W3C 标准说明，未读取该书全书正文；出版社目录不证明某种方法产生必然审美或传播效果。用途、受众、观看目的与交付情境的分栏是本条的项目转译，不是教材原样模板或行业统一规定。

## 项目转译

在简报中分别填写：用途（例如信息解释、品牌展示、商品细节、娱乐/情绪体验）、目标受众的可核实特征、预期观看目的、交付载体/画幅/时长/语言，以及可预期观看环境（声音是否可得、是否依赖小屏文字、是否需字幕/音频描述）。把"希望观众识别什么、理解什么、感受或考虑什么"写成创作假设，另列"需要什么受众证据才可验证"。

不要先承诺传播转化再倒推画面。先有作品/交付的可观察检查，再有受众测试；不同用途、版本、平台及人群分别留样，不能用单一"高级感"或"大众喜欢"替代定位。

## 可观察验收

- **通过**：简报的用途、受众、观看目的与交付情境均有具体内容；样片/图片中的主要信息与实际交付版本相符；适用时验证字幕/替代信息、语言、画幅及有声/无声观看。受众反应若已测试，应记录样本、材料、任务和结果，而非只写"有共鸣"。
- **失败**：只写"面向所有人""高端/有网感"；声称无声可懂却关键内容只在旁白；声称信息清楚但小屏交付中关键文字/细节不可辨；未实测却宣称点击、转化提升。
- **无法判定**：受众未招募或样本不足、实际投放环境未知、只由制作团队代答、没有基线或观看任务。此时只可判"简报完整性/技术可接收性"，不可判受众偏好、传播效果或转化。

## 不适用条件

- **不能推出**：受众/意图是创作规划维度，不等于人群有统一解读；可访问性合格不等于艺术或商业目标达成；观看目标不能直接推出点击、留存、转化，更不能推出特定镜头、色彩或明星必然有效。常见错误还包括把平台标签当受众研究、把"想让人感动"写成已发生的效果、把有声播放的检查结果外推到静音播放、把 WCAG 特定成功标准写成所有影像都必须配音描述、以团队审美替代目标受众核验。
- **结论边界**：本条未取得本项目目标受众的独立实测、平台受众数据、对照实验或传播转化数据，不能声称某受众定位已验证，也不能给出从"看懂/注意/喜欢"到点击、留存、购买等结果的因果或数值映射。来源为教材目录与标准说明，未经项目生成验证。
